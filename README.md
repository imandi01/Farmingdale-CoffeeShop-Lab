# Farmingdale-CoffeeShop
# ☕ Ram's Brew Order System

A Java-based coffee shop order management system developed as part of a Software Engineering lab assignment at Farmingdale State College.

This project simulates a campus coffee shop ordering system where users can create and customize beverage orders with different drink types, sizes, milk options, sweeteners, and espresso shots.

## Features

- Create different beverage types:
  - Coffee
  - Latte
  - Cappuccino
  - Tea
- Customize beverages with:
  - Size (Small, Medium, Large)
  - Milk (Whole, Skim, Almond, Oat, Soy)
  - Espresso shots (1–3 for espresso beverages)
  - Sweetener (Sugar, Honey, Stevia, None)
- Support multiple beverage options through an object-oriented design.
- Console-based order management system.

## Getting Started

### Prerequisites

- Java JDK 17 or later
- IntelliJ IDEA (or any Java IDE)

### Run the Project

1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/farmingdale-coffeeshop-lab.git
```

2. Open the project in IntelliJ IDEA.

3. Run `OrderDriver.java`.
